The Silent app screenshots per‑OS feature lets Owners, Organization Managers, and IT Managers control screenshot capture independently for macOS, Windows, and Linux. This is especially helpful because macOS requires a system‑level screen‑recording permission prompt, which interrupts users and reveals the Silent app. This feature is available only for organizations using the Silent app add‑on.
