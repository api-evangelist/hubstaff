The Hubstaff Tasks API lets you access and manage Hubstaff Tasks data programmatically. You can use it to build integrations, automate task workflows, and work with projects, lists, tasks, comments, labels, and other data stored in Hubstaff Tasks. Before you begin Your role and permissions determine what data your integration can access.
