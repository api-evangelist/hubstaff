The Insights Performance Report provides a single-glance dashboard of team productivity, measuring exactly how time is utilized compared to your set targets. It includes widgets for the metrics you want to review, such as utilization, activity levels, benchmarks, and work time classification. This feature is available with the Hubstaff Insights Add-on.
